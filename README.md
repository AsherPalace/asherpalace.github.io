# 三国通

[打开三国通](https://asherpalace.github.io/) · [直接猜人物](https://asherpalace.github.io/#game)

依据《三国志》的猜人物游戏与历史阅读沙盘。当前静态发布内容对应应用 v2.4。

- 160 位答案，633 个已收录身份可参与猜测。
- 猜测反馈只点关系方向；具体经过和正文依据在揭晓后查看。
- 明载派遣、任用、商议、师友或交锋优先提示；资料不足时，以有据的职务类型与籍贯同异补充方向，不由同阵营判断是否相识。
- 960 条可自主领取的多维生平提示。
- 有证亲属与实际往来优先参与关系接近度；区分父子、收养、兄弟、姻亲和从族关系，结合其他关系大类与语境拉开分值，不随机加小数。
- 九维统计保留为独立辅助参考，旧局刷新保留进度并重算关系主分。
- 人物、家族、正文阅读、地图与战役阶段示意。

## 阅读边界

本项目是有范围核读的历史学习工具，不是全书人工终审。未收录交汇不等于历史上绝无联系；关系分和九维辅助分均为游戏规则，不是交情概率或史实准确率，高关联也可能是敌对交锋。地形采用真实现代高程，古地名点位与行军路线为近似或阶段示意，不能当作古地理精确复原。

游戏在浏览器本地保存进度，无账号系统。不同网址、浏览器和设备的存档不自动共享。纯静态题库不提供服务端防作弊。
